# Dex Wep --- بوت تنزيل الفيديوهات عبر تيليجرام

السلام عليكم ورحمة الله تعالى وبركاته،


https://github.com/DarkDragonsX/Proxy-SYZ/blob/main/999f28ad02c0bd133b94760d1320a314.mp4


هذا المشروع عبارة عن بوت تيليجرام لتنزيل الفيديوهات من روابط عامة على
منصات متعددة، ثم إرسال الفيديو إلى المستخدم داخل المحادثة الخاصة مع
البوت. يعتمد المشروع على `yt-dlp`، مع إمكانية تجربة خدمة تنزيل خارجية
كخيار إضافي.

> **تنبيه:** يعتمد نجاح التنزيل على دعم المنصة للرابط، وتوفّر الفيديو
> للعامة، وتغيّر سياسات المنصات والخدمات الخارجية. لا يمكن ضمان تنزيل كل
> رابط أو ضمان أعلى جودة/سرعة في جميع الحالات.

## الميزات

-   استقبال رابط الفيديو من المستخدم ومعالجته تلقائيًا.
-   إرسال الفيديو إلى المستخدم عبر تيليجرام عند نجاح التنزيل.
-   استخدام `yt-dlp` للتنزيل المحلي، مع خيار خدمة خارجية احتياطية.
-   أوضاع تشغيل خدمة التنزيل: تلقائي، خارجي، ومحلي.
-   التحقق من اشتراك المستخدم في القنوات الإلزامية قبل السماح بالتنزيل.
-   لوحة تحكم خاصة بالأدمن لإدارة حالة الخدمة ومتابعة الإحصاءات.
-   إرسال رسالة جماعية للمستخدمين المسجلين في الذاكرة أثناء تشغيل البوت.
-   إدارة الأدمن والقنوات الإضافية من لوحة التحكم، بحسب الخيارات
    الموجودة في الكود.
-   وضع حد لحجم الفيديو ومدة التنزيل وعدد المهام المتزامنة، لتقليل الضغط
    على الخادم.
-   إظهار معلومات متاحة عن الفيديو عند توفرها.
-   تسجيل الأخطاء المهمة وإرسال تنبيهات للأدمن في بعض حالات الخطأ.
-   أمر إلغاء العملية الحالية أثناء استخدام خطوات لوحة الأدمن.

## المنصات المدعومة

قائمة النطاقات الموجودة حاليًا في الكود تشمل:

-   TikTok
-   Instagram
-   YouTube و`youtu.be`
-   Facebook و`fb.watch`
-   X / Twitter
-   Pinterest و`pin.it`
-   Threads

الدعم الفعلي يختلف حسب الرابط والمنصة. الروابط الخاصة أو التي تتطلب
تسجيل دخول أو ملفات تعريف ارتباط ليست جزءًا من طريقة الاستخدام المقصودة.
لا تستخدم البوت لتجاوز أنظمة الحماية أو تنزيل محتوى لا تملك إذنًا
بتنزيله.

## متطلبات التشغيل

-   Python 3.10 أو أحدث يُنصح به.
-   اتصال بالإنترنت.
-   بوت تيليجرام أنشأته عبر [@BotFather](https://t.me/BotFather).
-   مكتبات Python التالية:
    -   `python-telegram-bot`
    -   `yt-dlp`
    -   `requests`
-   `FFmpeg` اختياري، لكنه مفيد لدمج الصوت والصورة واختيار صيغ أفضل
    عندما يكون متاحًا.

## الإعداد لأول مرة

### 1. إنشاء بوت والحصول على التوكن

1.  افتح [@BotFather](https://t.me/BotFather) في تيليجرام.
2.  أرسل الأمر `/newbot` واتبع التعليمات.
3.  انسخ **Bot Token** الذي يعطيك إياه BotFather.
4.  لا تشارك التوكن مع أحد، ولا ترفعه إلى مستودع عام.

### 2. وضع التوكن في ملف Python

افتح الملف `dexwep.py` وابحث في قسم `CONFIGURATION` عن:

``` python
BOT_TOKEN = "Enter your bot token here "
ADMIN_ID = 7511400089
```

استبدل قيمة `BOT_TOKEN` بالتوكن الحقيقي، مثل:

``` python
BOT_TOKEN = "ضع_توكن_بوتك_هنا"
```

لا تضع مسافات إضافية داخل التوكن. في الخوادم أو المستودعات العامة،
الأفضل قراءة التوكن من متغير بيئة بدل كتابته مباشرة داخل الملف.

### 3. تعيين معرّف الأدمن

في السطر نفسه، غيّر `ADMIN_ID` إلى **رقم حساب تيليجرام الخاص بك**، وليس
اسم المستخدم أو رقم الهاتف:

``` python
ADMIN_ID = 123456789
```

يمكنك معرفة رقم حسابك عبر بوت موثوق يعرض Telegram user ID. تأكد من الرقم
قبل التشغيل، لأن هذا الحساب هو الأدمن الأساسي المحدد في الكود.

### 4. تثبيت المكتبات

من الطرفية داخل مجلد المشروع شغّل:

``` bash
python -m pip install --upgrade pip
python -m pip install python-telegram-bot yt-dlp requests
```

إذا كان أمر `python` يشير إلى إصدار غير مناسب في نظامك، استخدم `python3`
بدلًا منه.

### 5. تثبيت FFmpeg (اختياري)

ثبّت FFmpeg من مدير الحزم الخاص بنظام التشغيل أو من الموقع الرسمي، ثم
تأكد أن الأمر التالي يعمل:

``` bash
ffmpeg -version
```

إذا لم يكن FFmpeg مثبتًا، قد يختار البوت صيغة متاحة مباشرة، وقد لا يتمكن
من دمج بعض مسارات الصوت والفيديو المنفصلة.

## تشغيل البوت

من داخل المجلد الذي يحتوي على `dexwep.py`:

``` bash
python dexwep.py
```

اترك العملية تعمل حتى يبقى البوت متصلًا. لإيقافه يدويًا استخدم `Ctrl+C` في
الطرفية.

إذا كنت تستضيفه على خادم، استخدم طريقة تشغيل وإدارة العمليات المناسبة
لمزوّد الاستضافة، وراقب السجلات بعد التشغيل. لا تضع التوكن في لقطات
الشاشة أو سجلات عامة.

## طريقة الاستخدام للمستخدم

1.  افتح البوت الرسمي المحدد في إعدادات المشروع: **@TatsuLordbot**.
2.  اضغط **Start** أو أرسل `/start`.
3.  إذا طلب البوت الاشتراك في قناة إلزامية، افتح رابط القناة واشترك.
4.  ارجع إلى البوت واضغط زر التحقق من الاشتراك.
5.  أرسل رابطًا عامًا لفيديو مدعوم، مثل رابط TikTok أو Instagram أو
    YouTube.
6.  انتظر معالجة الرابط؛ سيحاول البوت تنزيل الفيديو ثم إرساله في
    المحادثة.
7.  إذا فشل الرابط، جرّب رابطًا عامًا آخر وتأكد من أن الفيديو متاح دون
    تسجيل دخول.

أرسل **الرابط فقط** في المحادثة الخاصة. إرسال ملف الفيديو نفسه ليس طريقة
التنزيل المطلوبة في هذا المشروع.

## لوحة الأدمن

تظهر لوحة الأدمن للحسابات التي يصرّح بها الكود. افتح البوت بحساب الأدمن
الأساسي وأرسل `/start` أو `/help`، ثم استخدم الأزرار المعروضة.

بحسب الخيارات المضمّنة في الملف، تشمل أدوات الإدارة ما يلي:

-   **حالة الخدمة:** تشغيل خدمة التنزيل أو إيقافها مؤقتًا.
-   **الإحصاءات:** عرض الإحصاءات التي يجمعها البوت أثناء التشغيل.
-   **حالة البوت:** الاطلاع على معلومات حالة التشغيل.
-   **المستخدمون:** عرض عدد المستخدمين المسجلين في الذاكرة الحالية.
-   **الإرسال الجماعي:** كتابة رسالة، مراجعتها/تأكيدها من خلال التدفق
    المخصص، ثم إرسالها إلى المستخدمين المسجلين.
-   **إدارة القنوات الإلزامية:** إضافة قناة أو إزالة قناة من خلال خطوات
    التأكيد الموجودة في اللوحة.
-   **إدارة الأدمن:** استخدام خيارات إدارة الأدمن المتاحة داخل اللوحة.
-   **خدمات التنزيل:** اختيار الوضع التلقائي أو الخارجي أو المحلي،
    وتحديث حالة الخدمات الخارجية.
-   **إلغاء العملية:** إلغاء تدفق إداري قبل إكماله.

قد تختلف أسماء الأزرار أو تفاصيل خطوات التأكيد بحسب النسخة الموجودة في
ملف `dexwep.py`. استخدم لوحة الأزرار داخل البوت بوصفها المرجع الفعلي
للأوامر المتاحة؛ ليست كل وظيفة الإدارية أمرًا نصيًا مستقلًا.

### ملاحظة مهمة عن التخزين

هذه النسخة تستخدم **الذاكرة المؤقتة داخل العملية** بدل قاعدة بيانات
دائمة. لذلك:

-   قائمة المستخدمين وإحصاءات التشغيل وبعض إعدادات الأدمن والقنوات التي
    تُضاف أثناء التشغيل قد تُمسح عند إعادة تشغيل البوت.
-   الأدمن الأساسي والقناة الإلزامية الأولية المحددان كثوابت في الملف
    يبقيان بعد إعادة التشغيل.
-   الإرسال الجماعي يصل إلى المستخدمين الذين سجّلهم البوت في الذاكرة
    الحالية فقط، وليس بالضرورة كل من استخدم البوت في الماضي.

## إعداد القنوات الإلزامية

تحتوي النسخة الحالية على قناة أولية محددة في الكود:

``` python
INITIAL_CHANNEL = {
    "chat_id": "@dexwep1",
    "join_url": "https://t.me/dexwep1",
    "title": "Dex Wep",
}
```

لتغييرها، عدّل القيم بما يناسب قناتك. اجعل البوت **مشرفًا في القناة** حتى
يستطيع التحقق من حالة اشتراك المستخدمين. يمكن إدارة القنوات الإضافية من
لوحة الأدمن إن كانت الميزة مفعّلة في النسخة الحالية.

## إعداد خدمة التنزيل الخارجية

يحتوي الكود على عنوان افتراضي لخدمة خارجية، ويمكن تغيير قائمة الخدمات
عبر متغير البيئة `DEXWEP_EXTERNAL_SERVICES`. ضع عناوين خدمات HTTPS التي
تملك حق استخدامها، وافصل بينها بفواصل.

مثال في Linux/macOS:

``` bash
export DEXWEP_EXTERNAL_SERVICES="https://your-authorized-service.example"
python dexwep.py
```

مثال في PowerShell:

``` powershell
$env:DEXWEP_EXTERNAL_SERVICES="https://your-authorized-service.example"
python dexwep.py
```

لا تستخدم العنوان المثال كما هو؛ استبدله بعنوان خدمة فعلي ومصرّح لك
باستخدامها. توافر الخدمات الخارجية وسياساتها قد يتغيران، ولذلك يتضمن
البوت مسارًا محليًا بديلًا عند اختيار الوضع التلقائي.

## حدود مهمة

الإعدادات الحالية في الملف تتضمن حدودًا لحماية موارد الخادم:

-   الحد الأقصى لحجم الفيديو: نحو **49,000,000 بايت**.
-   الحد الأقصى لمدة التنزيل: **180 ثانية**.
-   عدد مهام التنزيل المتزامنة: **2**.
-   سعة قائمة انتظار التنزيل: **20** مهمة.
-   مهلة بين طلبات المستخدم المتكررة: نحو **10 ثوانٍ**.
-   معالجة التنزيلات مصممة للفيديو الواحد، وليست لتنزيل قوائم تشغيل
    كاملة.

هذه حدود إعدادات داخل الكود، وقد تؤثر حدود تيليجرام أو المنصة المصدر أو
خدمة التنزيل على النتيجة أيضًا.

## حل المشكلات

### البوت لا يبدأ

-   تأكد من صحة `BOT_TOKEN`.
-   تأكد من تثبيت المكتبات المطلوبة.
-   تحقق من اتصال الإنترنت ومن سجل الأخطاء في الطرفية.
-   تأكد من تشغيل الملف الصحيح `dexwep.py`.

### البوت لا يتحقق من الاشتراك

-   تأكد أن اسم القناة ورابطها صحيحان.
-   أضف البوت مشرفًا في القناة.
-   تحقق من أن `chat_id` يطابق القناة المطلوبة.
-   راجع سجل التشغيل بحثًا عن أخطاء Telegram.

### رابط الفيديو لا يعمل

-   تأكد أن الرابط من منصة مدعومة وأن الفيديو عام.
-   جرّب الرابط الأصلي بدل رابط مختصر، إن أمكن.
-   حدّث `yt-dlp`:

``` bash
python -m pip install --upgrade yt-dlp
```

-   قد يكون الفيديو محذوفًا أو مقيّدًا أو أن المنصة غيّرت طريقة الوصول إليه.
-   جرّب وضع التنزيل الآخر من لوحة الأدمن إذا كان متاحًا.

### الفيديو أكبر من الحد المسموح

استخدم رابطًا أو جودة ينتج عنها ملف أصغر، أو عدّل حدود المشروع بعد فهم
تأثيرها على الذاكرة والوقت وقيود رفع الملفات في تيليجرام. رفع الحد وحده
لا يضمن أن تيليجرام سيقبل الملف.

## الخصوصية والاستخدام المسؤول

-   لا تضع توكن البوت أو أي أسرار في مستودع عام.
-   لا تضف ملفات تعريف ارتباط أو بيانات تسجيل دخول للمستخدمين.
-   نزّل المحتوى الذي تملكه أو لديك إذن بتنزيله، واحترم حقوق النشر وشروط
    المنصات.
-   لا تحاول تجاوز DRM أو أنظمة الحماية أو قيود الوصول.
-   إذا نشرت المشروع للعامة، وضّح للمستخدمين حدود الخدمة وسياسة التعامل
    مع البيانات.
