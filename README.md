# 🌐 Proxy-SYZ

**Proxy-SYZ** هي أداة متكاملة لجلب وفحص البروكسيات المجانية من الإنترنت بسرعة ودقة عالية.  
https://raw.githubusercontent.com/DarkDragonsX/Proxy-SYZ/refs/heads/main/1769626037039.png
تساعدك هذه الأداة في الحصول على بروكسيات صالحة وموثوقة، حيث تقوم بجلب آلاف البروكسيات من مصادر مختلفة، ثم تتحقق من صلاحيتها عبر اختبارها على عدة مواقع شهيرة، وتصنفها حسب جودتها (سريعة، بطيئة، أو غير صالحة).  

يمكنك حفظ البروكسيات الصالحة في ملف تختاره، مع إمكانية دمج البروكسيات البطيئة مع السريعة.  

الأداة سهلة الاستخدام، وتدعم أنظمة Windows، Linux، وأندرويد.

أكيد، هذا شرح لكل ميزة على حدة مع شرح مبسط لكيفية عملها، خصوصًا طريقة التحقق من البروكسي:



https://youtu.be/kXBzhzOOygA?si=57dzDLc6BQQZyRwM

✨ ميزات Proxy-SYZ 

تحميل البروكسيات من مصادر متعددة
تجمع الأداة بروكسيات HTTP مجانية من عدة مواقع موثوقة حول العالم، لتضمن لك أكبر عدد ممكن من الخيارات.





---

طريقة التحقق من البروكسيات
الأداة تتحقق من كل بروكسي عبر تجربة الاتصال بأكثر من موقع شهير (مثل Google، Facebook، Instagram، وapi.ipify.org) لتتأكد من أن البروكسي:

يعمل فعلاً (يغير عنوان IP)

ليس محظوراً أو ميتاً

سرعة استجابته ضمن الحدود المقبولة
إذا فشل البروكسي في الاختبار على أي من هذه المواقع، يتم تصنيفه كبروكسي ميت أو بطيء.




---

تصنيف البروكسيات إلى سريعة وبطيئة وميتة
بعد التحقق، يتم تقسيم البروكسيات إلى:

سريعة: استجابتهم سريعة جداً وصالحة للاستخدام الفوري

بطيئة: تستجيب لكن ببطء قد يؤثر على الأداء

ميتة: لا تستجيب أو محظورة




---

حفظ البروكسيات الصالحة حسب اختيارك
يمكنك تحديد مكان حفظ البروكسيات التي تعمل، مع خيار دمج البروكسيات البطيئة مع السريعة أو حفظها منفصلة.



---

واجهة تفاعلية ملونة وسهلة الاستخدام
تعرض الأداة تقدم الفحص والتصنيف بشكل ملون وواضح مع رسائل تساعدك في معرفة حالة كل بروكسي.



---

معالجة أخطاء ذكية
إذا حدث أي خطأ أثناء التحميل أو الفحص، الأداة تعطيك شرح عن المشكلة ونصائح للحل، ولا تتوقف فجأة.

## 🚀 طريقة التنزيل والتشغيل مع أوامر نسخ

---

### 1. استنساخ المستودع من GitHub

```bash
git clone https://github.com/DarkDragonsX/Proxy-SYZ.git
```
انسخ الأمر أعلاه والصقه في الطرفية لتنزيل الأداة.





2. الانتقال إلى مجلد المشروع
```bash
cd Proxy-SYZ
```
انتقل إلى مجلد الأداة بعد تنزيلها.


---

3. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```
ثبت المكتبات اللازمة لتشغيل الأداة.




4. تشغيل الأداة
```bash
python proxy_syz.py
```
شغّل الأداة بعد تثبيت المتطلبات.
